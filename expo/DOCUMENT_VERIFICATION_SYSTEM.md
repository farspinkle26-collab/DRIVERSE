# Document Management & Verification System\n\nA comprehensive document management and verification system for your towing app that enables strict account separation and verification workflows.\n\n## 🎯 Overview\n\nThis system provides a complete solution for managing document uploads and verification processes for different account types (Driver/Company). It ensures that users cannot simply switch roles - they must go through formal registration and verification processes.\n\n## 🏗️ System Architecture\n\n### Core Components\n\n1. **Document Types Management**\n   - Configurable document requirements per account type\n   - File type and size validation\n   - Active/inactive status control\n\n2. **Document Upload System**\n   - Secure file upload with validation\n   - Progress tracking and status updates\n   - Support for images and PDFs\n\n3. **Admin Verification Dashboard**\n   - Review and approve/reject documents\n   - Bulk operations and filtering\n   - Detailed verification statistics\n\n4. **User Verification Flow**\n   - Step-by-step document upload process\n   - Real-time status tracking\n   - Rejection reason handling\n\n## 📋 Document Types\n\n### Driver Account Requirements\n- **KTP (ID Card)** - Indonesian National Identity Card\n- **SIM (Driver License)** - Indonesian Driver License  \n- **STNK (Vehicle Registration)** - Vehicle Registration Certificate\n- **Bank Account Statement** - For payout verification\n\n### Company Account Requirements\n- **KTP (ID Card)** - Contact person identification\n- **Business License** - Company Business License (SIUP/NIB)\n- **Tax Certificate** - Company Tax Certificate (NPWP)\n- **Bank Account Statement** - For payout verification\n\n## 🔄 Verification Workflow\n\n### User Flow\n1. **Document Upload**\n   - Select account type (Driver/Company)\n   - Upload required documents\n   - Validate file types and sizes\n   - Track upload progress\n\n2. **Review & Submit**\n   - Review uploaded documents\n   - Submit verification request\n   - Receive confirmation\n\n3. **Status Tracking**\n   - Monitor verification status\n   - Receive notifications\n   - Handle rejections\n\n### Admin Flow\n1. **Dashboard Overview**\n   - View pending requests\n   - Monitor verification statistics\n   - Filter by status/type\n\n2. **Document Review**\n   - View document details\n   - Approve/reject individual documents\n   - Add review notes\n\n3. **Request Management**\n   - Approve/reject entire requests\n   - Provide rejection reasons\n   - Track review metrics\n\n## 🛡️ Security Features\n\n- **File Validation**: Type and size restrictions\n- **Secure Upload**: Protected file handling\n- **Access Control**: Role-based permissions\n- **Audit Trail**: Complete verification history\n- **Data Protection**: Secure document storage\n\n## 📊 Admin Features\n\n### Verification Dashboard\n- Real-time statistics and metrics\n- Pending/approved/rejected counters\n- Average review time tracking\n- Recent activity monitoring\n\n### Document Management\n- Individual document review\n- Bulk approval/rejection\n- Detailed rejection reasons\n- Document preview capabilities\n\n### User Management\n- Account status control\n- Verification history\n- Communication tools\n- Dispute resolution\n\n## 🔧 Technical Implementation\n\n### State Management\n```typescript\n// Document verification store with comprehensive state management\nconst {\n  documentTypes,\n  userDocuments,\n  verificationRequests,\n  stats,\n  uploadDocument,\n  reviewDocument,\n  submitVerificationRequest\n} = useDocumentVerification();\n```\n\n### Key Components\n- `DocumentUploadComponent` - File upload interface\n- `DocumentVerificationScreen` - User verification flow\n- `AdminVerificationDashboard` - Admin review interface\n- `useDocumentVerificationStore` - State management\n\n### File Upload\n- Uses `expo-document-picker` for file selection\n- Supports images (JPEG, PNG) and PDFs\n- Configurable size limits per document type\n- Progress tracking and error handling\n\n## 🚀 Usage\n\n### For
